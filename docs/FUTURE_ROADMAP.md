# ProofHire - Future Roadmap

## Q1 2027: Deep AI Verification
- Implement LLM-based repository deep-scan to detect Plagiarism.
- Automated evaluation of System Architecture Diagrams via Computer Vision + LLMs.
- Launch the "ProofHire Capability API" for 3rd-party ATS integrations (Greenhouse, Workday).

## Q2 2027: Interactive Hackathons
- Host internal mini-hackathons (4-hour challenges) directly on the platform.
- Real-time multiplayer coding environments for pair-programming interviews.
- Integrate WebAssembly (Wasm) for executing and testing submitted code securely in the browser.

## Q3 2027: Enterprise Features
- Advanced Recruiter Analytics Dashboard (Time-to-hire, Candidate skill distribution).
- Diversity & Inclusion algorithms to ensure bias-free capability rankings.
- Integration with LinkedIn for seamless profile importing while forcing verification.

## Q4 2027: Decentralized Verification (Web3)
- Explore publishing "Technical Capability Passports" to a public blockchain or decentralized identity network (DID) so candidate scores are globally verifiable and immutable.
